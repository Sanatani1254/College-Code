1. Introduction
Data visualization makes it easier to understand information, especially when working with large datasets. In business, it helps us get a clear picture of sales, profits, customer orders and product performance. Instead of going through thousands of records manually, charts and graphs are used to identify patterns and trends.
In this project, I have developed an interactive dashboard using the Sample Superstore dataset. The main purpose is to analyse product sales and profits across different categories and regions. It also explores how discounts are related to profits and how sales change over time.
The dashboard is developed using Python and Streamlit, while Plotly is used to create the visualizations. It also includes filters that allow users to explore different parts of the dataset without having to analyse the entire data at once.
2. Problem Statement
Large amount of data is generated by buissnesses. However, that data needs to be properly studied to understand business performance and identify areas that may need improvement.
Some of the questions that this project focuses on are:
• Which product categories generate the highest sales?
• Which sub-categories are generating the lowest profits?
• How do sales change over different months?
• Which region contributes the most to total sales?
• Is there any noticeable relationship between discounts and profits?
The main objective is to answer these questions through an interactive dashboard that presents the data in a simple and understandable way.
3. Objectives
The main objectives of this project are:

• To create an interactive dashboard with useful KPIs and filters.
• To study sales and profit trends over time.
• To examine the relationship between discounts and profits.
• To compare the performance of different product categories and regions.
• To present the results through suitable charts and visualizations.
4. Data Description
For this project, I have used the Sample Superstore dataset. It contains retail transaction records with information about orders, products, sales and profits. The version loaded here has 9,994 records covering orders placed between January 2014 and December 2017.
Some of the important columns used in the analysis are:
• Order ID (Unique identification of an order)
• Order Date (Date on which the order was placed)
• Region (Region where the order was placed)
• Category (Main product category)
• Sub-Category (Specific type of product)
• Sales (Amount generated from sales)
• Profit (Profit or loss from a transaction)
• Quantity (Number of products ordered)
• Discount (Discount applied to the order)
Dataset Source: https://github.com/edusatyaki/Dataset/blob/main/Sample%20-%20Superstore.CSV
The dataset is loaded directly from the public CSV source. An additional option is provided in the dashboard to upload another compatible CSV file for analysis.

6. Data Cleaning and Preparation
The dataset needed some preparation before creating the visualizations. This was done to avoid incorrect values and make the analysis more reliable.
The following steps were performed:
1. Removing duplicates
Exact duplicate records were removed so that the same transaction would not be counted more than once.
2. Converting dates
The Order Date column was converted into the proper date format. Records containing invalid dates were removed.
3. Handling numerical values
Columns such as Sales, Profit, Quantity and Discount were converted into numerical data types wherever required.
4. Handling missing values
Rows with missing or invalid values in important columns such as Order Date, Sales and Profit were removed.
For other columns, the following approach was used:
• Missing Region, Category and Sub-Category values were replaced with "Unknown".
• Missing Quantity and Discount values were filled using the median of their respective columns.
5. Data validation
The dashboard also checks whether the required columns are available before starting the analysis. It handles situations where the dataset is empty or the selected filters do not return any records.
These steps help maintain consistency in the dataset and reduce problems during analysis. When I ran them on the Superstore dataset, they found 0 duplicate rows and 0 rows with missing or invalid values, so all 9,994 records were kept.
7. Dashboard and Visualizations
The dashboard contains four main KPIs, interactive filters and six visualizations. Each chart focuses on a different aspect of the sales and profit data. All figures below are for the full dataset with no filters applied.
7.1 Key Performance Indicators (KPIs)
Four KPIs are displayed at the top of the dashboard to give a quick overview of the selected data.
• Total Profit: Displays the total profit generated ($286,397.02).
• Profit Margin: Represents the percentage of profit earned relative to total sales (12.47%).
• Total Sales: Shows the total sales amount for the selected records ($2,297,200.86).
• Total Orders: Shows the number of unique orders (5,009).
These values update automatically when the user changes the filters.
7.2 Sales Over Time
To make data visually easy to analyze line chart are used,
By looking at this chart, we can observe whether sales are generally increasing, decreasing or how there trends are changing throughout the selected period.
Observation: The highest month was November 2017, with about $118,448 in sales. Yearly sales dropped slightly from about $484K in 2014 to $471K in 2015, then rose to $609K in 2016 and $733K in 2017. The chart also shows a seasonal pattern: September, November and December are strong every year, while February is the weakest month. The lowest single month was February 2014, at about $4,520.

7.3 Profit by Sub-Category
This horizontal bar chart compares the total profit generated by different product sub-categories.
It helps identify which products contribute more towards profit and which ones perform poorly. Sub-categories with very low or negative profits can be examined further.
Observation: Copiers made the most profit ($55,618), followed by Phones ($44,516) and Accessories ($41,937). Three sub-categories lost money: Tables (-$17,725), Bookcases (-$3,473) and Supplies (-$1,189). Tables was the worst by a large margin.

7.4 Discount vs Profit
To determine the relation between the discount offered and the profit generated scatter plot is used.
By looking at the distribution of points, we can check whether higher discounts are generally associated with lower profits or whether there is no clear pattern.
Observation: The relationship is weak and negative (correlation of about -0.22). Orders with no discount averaged about $67 profit, while orders with a 20 to 30% discount averaged a loss of about $46. About 98% of orders with a discount above 30% lost money. This does not prove that discounts cause the losses. Discounts may have been given more often on products that already had low margins, such as Tables.

bar chart compares the total sales generated by different product categories.

7.7 Profit by Category
A box plot is used to compare the distribution of profits across different product categories.
Unlike a normal bar chart, it shows more information about the data, including the median, spread and outliers. This helps us understand how consistent the profits are within each category.
Observation: Technology has the highest median profit per order (about $25), compared with about $7.8 for Furniture and $6.9 for Office Supplies. Technology also has the widest spread and the most extreme outliers, ranging from a loss of $6,600 to a profit of $8,400. For most orders in every category, the profit is close to zero.
In total profit, Technology made $145,455 and Office Supplies $122,491. Furniture made only $18,451 even though it was the second-highest in sales, so it earns very little profit per dollar sold.

8. Interactive Features
The dashboard includes several features that allow users to explore the dataset according to their requirements.
• Date Range Filter: Restricts the analysis to a particular time period.
• Region Filter: Allows users to select one or more regions.
• Category Filter: Displays results for selected product categories.
• CSV Upload: Allows users to upload their own compatible dataset.
• Dynamic KPIs and Charts: All displayed values and visualizations update according to the selected filters.
• Download CSV: Allows users to download the filtered dataset.
• Data Cleaning Summary: Displays information about duplicate records and missing values handled during data preparation.
• Key Insights: Writes out the top category, top region, lowest-profit sub-category and totals for the selected filters.
These features make the dashboard more flexible and allow users to focus on specific parts of the data.
9. Key Findings
After exploring the dataset through the dashboard, the following observations can be recorded:
1. Highest Sales Category: Technology generated the highest total sales ($836,154).
2. Best Performing Region: West recorded the highest sales ($725,458).
3. Lowest Profit Sub-Category: Tables had the lowest total profit (-$17,725).
4. Highest Sales Month: November 2017 recorded the highest sales (about $118,448).
5. Discount and Profit: The scatter plot shows a weak negative relationship between discounts and profits. Heavy discounts, especially above 30%, are almost always loss-making.
6. Profit Distribution: The box plot indicates that Technology has the highest median profit, but also the widest spread and the most extreme outliers. Most orders in all categories earn very little.
7. Sales vs Profit: Furniture is second in sales but last in profit, so high sales do not always mean high profit.
These observations provide a better understanding of the business performance. They also help identify product categories and regions that may require further attention, such as Tables, Bookcases, high discount levels and the Furniture category in general.
