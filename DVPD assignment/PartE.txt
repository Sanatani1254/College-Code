Data Visualization plays an important role in the present world. It helps us understand how our businesses are performing, and enables us to make data driven decisions. Within large sets of data we can understand how much money our company is making, how many orders are being placed and how well certain product categories are selling. It can be difficult to find meaningful patterns from this data however.

This project aims to create an interactive dashboard which shows various pieces of information based on product sales, categories, regions, discounts and profits using the Sample Superstore dataset. The dashboard will be created using Python and Streamlit. Visualisations will be created using Plotly.

2. Problem Statement Retail businesses collect large amounts of data from their transactions. However without analysing this data it can be difficult to answer the following questions:

What product categories have the most sales?

What product subcategories have the lowest profits?

How do sales vary over time?

What regions have the most sales?

Is there any correlation between discounts and profits?

The aim of this project is to create an interactive dashboard to show this information using the data from the Sample Superstore dataset.

The aim of this project is to answer these questions by creating an interactive dashboard to show the business data clearly.

6. Data Cleaning

Some data preparation was performed to ensure better quality data.

Remove duplicates

Any exact duplicate rows were removed.

Convert dates

The Order Date was converted to proper date time format. Any invalid dates were removed.

Convert numbers

Sales, Profit, Quantity and Discount were converted to numbers.

Handle missing data

Rows where Order Date, sales or profit were missing or invalid were removed.

Where region, category or sub-category were missing they were assigned the value "Unknown".

Where quantity or discount were missing they were filled in with the median of the column.

Validation

The dashboard ensures that the necessary columns are present before analysing. It also handles cases where there is no data, or invalid filter options.

This ensures that the data is consistent and the visuals are reliable.
